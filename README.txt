TREND INDIA — Version 1.0 starter prototype

WHAT THIS IS
- A responsive, bilingual (Hindi/English) social app interface.
- Includes sample feed, demo likes, comment box toggle, and local post preview.
- It does NOT yet have real accounts, online uploads, chat, cloud storage, moderation, or a live database.

FILES
- index.html: app interface
- manifest.webmanifest: installable web app metadata
- sw.js: basic offline cache

HOW TO TRY ON YOUR PHONE
1. Extract this ZIP.
2. Host the three files on an HTTPS static host (for example, GitHub Pages).
3. Open the published HTTPS address in Chrome on Android or Safari on iPhone.
4. Android: browser menu > Install app / Add to Home screen.
5. iPhone: Share > Add to Home Screen.

IMPORTANT
This starter is a prototype, not a published Play Store or App Store app.
Do not collect real passwords or personal information in this demo.
For a public launch, add authentication, secure backend/database/storage, reporting/blocking,
privacy policy, terms, age-appropriate safety controls, and test on multiple devices.
